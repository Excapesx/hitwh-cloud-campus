# 哈工威 · 云上校园

根据用户提供的校园地图，在原 `HITWH-Cloud-Campus.html` 雏形上完善的三维校园导览。保留原来的绿色界面、第一人称漫游、建筑碰撞与俯瞰模式，重新整理校园布局。

## 直接使用

下载仓库根目录的 **`index.html`**，用支持 WebGL 2 的 Chrome 或 Edge 双击打开。交付文件约 2.7 MB，已包含 Three.js、界面及原始地图，打开时不依赖 CDN 或网络。若设备不支持三维渲染，启动页提供查看原图入口。

## 本次完善

- 依据地图描绘校园轮廓、北侧山体、西侧海岸、15 段主要道路与步道。

- 建筑目录、分类、搜索与无结果恢复；点击建筑或目录可聚焦镜头并查看说明。

- 保留 WASD 第一人称移动、鼠标环顾、E 查看与碰撞；可从选中建筑附近进入漫游。
- 手机触摸旋转、双指缩放与窄屏控制栏；遵循系统减少动态效果设置。
- 南门已依据三张实景照片细化三通道拱门、槽纹柱、檐口、校名牌匾、敞开铁艺门及门前设施；入口页可选择“查看南门细节”。详见 [南门细化说明](docs/SOUTH-GATE.md)。
- 增加墙面与沥青纹理、石材微起伏、玻璃和金属反射、日光天空及局部高清阴影；桌面南门近景包含接触阴影。详见 [材质光影说明](docs/REALISM.md)。

## 操作

| 模式 | 操作 |
| --- | --- |
| 俯瞰 | 拖拽旋转；滚轮或加减按钮缩放；点击建筑定位 |
| 键盘俯瞰 | 聚焦三维画面后，方向键旋转、`+` / `-` 缩放、`Home` 复位 |
| 第一人称 | 桌面浏览器允许鼠标锁定后，WASD 移动、鼠标环顾、E 查看建筑、Esc 释放鼠标 |
| 手机 | 单指旋转、双指缩放；通过目录选择地点 |
| 时间与天气 | 底部“天气 · 时间”打开控制；拖动全天时间，或选清晨、正午、黄昏、夜晚；支持六种天气、强度和粒子开关 |

“地标巡览”是依次查看六个地标的镜头演示，不提供步行路径或测距。自动旋转默认关闭。

天气支持晴天、多云、阴天、雨天、雪天、雾天。天空、日光方向、阴影、雾、湿润表面及雪色联动；夜间亮起窗格、南门路灯和立面照明。可播放昼夜变化，选择 1、5、15 分钟走完一天；默认停在晴天 14:00。本地保存设置，重新打开时暂停播放。“复位”只恢复镜头，天气面板内“恢复晴天下午”恢复环境。时间和天气为展示模拟，不接入实时气象或指定日期的太阳历算。

主楼根据用户提供的五张照片修正：正面和两翼前庭朝向南门，主楼—弧形柱廊—校训石—南门共用一条中轴线。开始页可选“查看主楼与中轴线”，主楼详情可在正面和完整轴线之间切换；`index.html#main` 和 `index.html#main-axis` 分别直达两个视角。柱廊和校训石是场景景观，不增加目录建筑计数。

最新细化结合柱廊近照、冬夏航拍和南门中轴总览重新校准比例：主楼加宽并降低塔楼的相对高度，柱廊收窄、降低并与主楼拉开距离，校训石及南门采用一致场景尺度。柱廊为双排 24 柱，带叶饰柱头、凹槽柱身、石砌基座、檐口饰板和拱形饰冠；主楼增加窗框窗台、玻璃分格、栏杆、齿饰、门扇及雨棚细节。详情中的“查看柱廊细节”或 `index.html#colonnade` 可进入近景。所有比例仍为照片估计。

中轴布局按“笔直、对称”的反馈进一步整理：南门门体、入口铺装、灯具与主楼共用朝向；中央大道和步道保持直线，两侧湖区、绕湖步道与树列成对布置。移除旧版斜穿的小路及独立矩形铺装，校训石置于中央椭圆石材广场。中轴总览镜头正对轴心，手机单独调整取景比例。详见 [中轴对齐说明](docs/AXIS-ALIGNMENT.md)。

校训石南侧的展示区按近照加入红色齿轮拱、1985 与 2026 年份底座、HIT 书本和花坛。展示区两侧可步行绕往校训石，红色灯带与年份随昼夜点亮。主楼详情中的「查看校训石前立牌」或 `index.html#display` 可直达近景，其中的「到附近漫游」从立牌南侧开始。细节与验证见 [立牌说明](docs/COMMEMORATIVE-DISPLAY.md)。

道路和树阵参考新增道路实拍细化。主路增加连续路缘、人行带、黄中心线和白边线，法桐式树阵改为多簇宽冠，树干带白色涂干与橙色警示带。详见 [道路与树阵细化](docs/ROADSCAPE-DETAILS.md)。

## 开发与构建

需要 Node.js 与 npm。

```sh
npm ci
npm run build
npm run check
npm run dev
```

预览地址：`http://127.0.0.1:4177`。修改源码后重新运行 `npm run build`，刷新预览。`index.html` 是可重复生成的交付物，与源码一同提交；无需把 `node_modules` 发给客户。

| 路径 | 用途 |
| --- | --- |
| `src/index.html` / `src/styles.css` | 界面模板与样式 |
| `src/app.js` | 保留并扩展的渲染、漫游、碰撞与界面交互 |
| `src/campus-data.js` | 原图归一化坐标、地点、道路、湖泊与校园边界 |
| `src/model.js` | 地形、道路及建筑体量生成 |
| `src/south-gate.js` | 南门照片细化模型、材质合并与局部碰撞体 |
| `src/main-axis.js` | 主楼照片细化、弧形柱廊、校训石与前庭；轴线坐标定义于 campus-data.js |
| `src/colonnade.js` | 双排柱廊的石砌基座、凹槽柱身、叶饰柱头与曲面檐口 |
| `src/commemorative-display.js` | 校训石前的齿轮拱、年份底座、书本与花坛 |
| `src/realism.js` | 程序化表面、日光环境、局部阴影与近景后期处理 |

| `reference/HITWH-Cloud-Campus.original.html` | 用户原雏形，原样保存用于对照 |
| `LICENSES/three.txt` | Three.js 的 MIT 许可；同时嵌入交付 HTML |

## 精度与素材

当前是**地图驱动的程序化三维示意模型**。平面布局参照用户地图人工描绘，建筑高度、层数、立面、简化轮廓及绿化为示意；场景单位不等于测绘米数。地图日期及当前现场开放情况未核实。本项目不宣称实景扫描、测绘精度或实时导航。

如需照片级实景，应进一步提供楼宇照片、无人机影像、测绘坐标或经授权的 glTF/GLB、摄影测量或 3D Gaussian Splatting 数据。

项目仓库：[Excapesx/hitwh-cloud-campus](https://github.com/Excapesx/hitwh-cloud-campus)。原 HTML 与地图来自用户提供，保留其原有权利；本仓库不额外授予这些素材的使用许可。
