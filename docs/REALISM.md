# 日间材质与光影细化

本次以南门近景为主要观察对象，保持建筑结构、照片参照和校园导览流程，细化材质与渲染。

## 可见变化

- 墙面与石材使用世界坐标程序化纹理：轻微颜色变化、表面微起伏、粗糙度变化和接近地面处的轻度积尘。
- 沥青加入细颗粒及缓慢变化的色差；人行铺装增加接缝和细微起伏，原校园道路与门前铺装使用一致的沥青材质。
- 立柱、门廊和檐线的矩形构件增加细小圆角，利于自然高光过渡。
- 玻璃使用较低粗糙度与表面清漆反射，铁艺、灯杆区分反射强度和粗糙度；校名牌匾增加凹凸细节。
- 分析式日光天空提供环境反射，以暖色方向光为主、低强度天空补光为辅。调整 AgX 色调映射，保留亮部层次。
- 南门近景将阴影范围收紧至局部，以提高柱脚、门廊和檐口的阴影精度；返回全校时恢复全局阴影范围。
- 桌面近景启用 GTAO 接触阴影与降噪，补足转角和接触处的遮蔽。手机窄屏关闭这道后期处理，保留材质、环境反射和方向光阴影。
- 增加南门两侧的分层树冠，改善近景的绿化层次；其他树冠增加分段和边缘变化。

## 交付与性能范围

所有程序化材质、天空和渲染代码随 `index.html` 打包，无需联网加载贴图或 HDR 文件。文件约 2.74 MB。接触阴影仅在南门近景且视口宽度不小于 700px、设备支持浮点渲染目标时启用；其余情况直接渲染。几何与材质合批仍保留。

材质与光照效果受设备、屏幕及浏览器影响。窄屏检查不是实际手机的性能验收；没有承诺统一帧率。新增树木与表面纹理为程序化表达，整体仍属于依据地图及照片细化的模型，未变成摄影测量或扫描实景。
