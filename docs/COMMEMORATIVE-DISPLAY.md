# 校训石前纪念立牌

## 位置关系

用户补充的航拍和近照显示：南门向主楼方向前进时，先经过纪念立牌，再到校训石、中央步道、弧形柱廊和主楼。立牌放在中轴 `distance=123`，校训石在 `distance=111`；立牌前场在 `distance=128` 收口，南门中轴路从这里向南门继续。

## 细节

- 红色齿轮拱由两道有厚度的半圆拱、外圈齿块、内外红色灯带和两侧蓝色飘带组成。
- 左右红色底座使用照片中的 `1985` 与 `2026`，数字为实体分段构件；中间是带红色封面、白色纸页和 `HIT` 字样的翻开书本。
- 底部为低白栅栏和黄红色低矮花坛，展示区两侧留出步行绕行空间。
- 校训石保持在立牌后方，立牌不新增目录地点，不改变原有 69 处地点计数。
- 红色轮廓和年份材质接入天气系统的昼夜亮度；展示近景使用独立阴影范围和 GTAO。

模型依据照片进行视觉比例估计，不代表实测尺寸；未把用户照片、水印或宣传文字作为发布素材。
