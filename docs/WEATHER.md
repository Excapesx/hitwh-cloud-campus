# 时间与天气系统

入口在底部“天气 · 时间”。保留现有导览与单文件离线交付，新增：

- 场景时间 00:00–23:55，以 5 分钟为手动步长；播放时内部连续推进并跨午夜循环。
- 清晨 06:30、正午 12:00、黄昏 17:30、夜晚 21:00 快捷选项；1 / 5 / 15 分钟一天，播放和暂停。
- 晴天、多云、阴天、雨天、雪天、雾天；天气强度 0–100%，晴天无须调整强度。
- 日光方向、色温、天空云层、环境反射、阴影与能见度联动。雨天调整表面颜色和粗糙度；雪天为朝上的表面添加雪色。
- 雨雪粒子可单独关闭，强度为 0 时不显示。窄屏最多 850 个、桌面最多 1800 个，按强度减少；粒子落到建筑占地的估算屋顶高度后重生。
- 夜间窗格自发光，南门灯头、路灯照明和立面洗墙灯联动。四盏聚光灯不另投射阴影。
- 设置使用本地存储；读取失败、非法值或不可用时回退。重新打开保持场景设定但暂停时间播放。镜头“复位”与环境重置各自独立。

## 实现与边界

`weather-state.js` 为可独立检查的纯状态与氛围计算；`weather.js` 管理 UI、材质天气参数、灯光、降水和保存；`realism.js` 负责动态解析天空、环境反射和阴影。环境贴图更新按时段与天气分档，最频繁每 1.8 秒一次，并释放上一张贴图；动态阴影最多约每 150ms 更新一次，近景切换立即更新。

太阳轨迹是用于展示的艺术模拟，未按地图朝向、具体日期或地理坐标标定。天气由用户控制，无气象服务或网络依赖。雪色不代表真实积雪厚度，粒子只使用简化屋顶/地形高度，不是流体或精细碰撞模拟。减少动态偏好下，粒子和云层静止；用户仍可主动播放昼夜。页面隐藏时不推进时间，恢复后不补播后台时长。

主要接口依据：[Three.js Sky](https://threejs.org/docs/pages/Sky.html)、[ShaderMaterial](https://threejs.org/docs/pages/ShaderMaterial.html)，同时对照本仓库锁定的 Three.js 源码。
