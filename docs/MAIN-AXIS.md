## 修正内容

`campusAxis` 以原地图主楼中心与南门中心的连线定义局部方向，主楼正面为局部 +Z。原先向背面伸出的两翼改为朝向南门围合前庭，通用坡屋顶替换为平屋面、分层檐口。重做浅色立面、深绿窗格、半圆顶窗、巨柱与三角山花、入口雨棚、台阶、逐层收分的塔楼、角部尖饰和细长天线。

沿同一坐标系加入弧形柱廊、前庭铺装、南门中轴路和校训石分流岛；校训石面向南门。柱廊使用 12 根立柱，中央两柱间留出通道。随机树木避开前庭与轴线通道。小地图同步显示大道、柱廊与校训石。目录数量仍为 69，新增景观不计为独立建筑。

主楼采用独立合批模块 `src/main-axis.js`；建筑地面占地、立柱和校训石登记碰撞体。近景阴影和 GTAO 可聚焦主楼，雨雪局部粒子也跟随主楼区域，避免沿用南门中心。夜景轮廓与窗格跟随已有时间系统。

新增开始页入口、主楼详情的“查看完整中轴线 / 查看主楼正面”，以及 `#main-axis` / `#main` 深链接。完整轴线视角同时显示主楼、柱廊、石、南门。

## 精度边界

主楼中心仍使用人工描图坐标；沿主楼与南门连线布置轴线，未重新测绘校园。柱廊 44、校训石 121、轴线约 167 的位置值均为场景比例单位，不是米；柱数、细部尺度、建筑高度和灯光均按照片估计。照片不足以恢复全部背面、楼内空间和真实结构，不宣称测绘或扫描精度。
