# 校园导览界面

## Direction contract

THESIS：在用户原雏形上校准地图并完善可用性，保留绿色浮动控制栏与三维画面优先的结构。

OWN-WORLD：继承原雏形的深绿文字、浅绿地形、米白面板和偏蓝海面，保留已有窗格、屋顶、树木和建筑拾取方式。

STORY：用户从俯瞰或第一人称进入校园，通过建筑目录、搜索或点击识别地标；可打开用户原图校对位置。

FIRST VIEWPORT：全屏三维校园，左上品牌、右上布局小地图、底部控制栏；目录与详情按需出现，手机控制栏换为两行。

FORM：原雏形的局部扩展；地图相对位置为约束，不替换原有视觉世界。采用源码拆分、构建单文件 HTML 的方式。无批准的新视觉稿。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 完成证据

初版独立复核 disposition：ship。桌面与手机俯瞰截图、源码已复核；浏览器交互、离线文件与第一人称移动另见 VALIDATION.md。原图有来源元数据；没有生成式图片素材。

南门照片细化保留上述界面规则，增加局部建筑材质与正面近景。已检查稳定镜头的桌面、手机截图，并实际由临街侧穿过中央拱门；本次检查范围见 SOUTH-GATE.md。

后续日间质感细化保留 UI 布局，增加程序化微表面、天空环境反射、局部日光阴影和桌面接触阴影，验证范围见 REALISM.md。

时间与天气扩展保留导览界面，在底部加入按需展开的环境控制。桌面夜景、雨天和手机雪景已实机截图检查；全天时间、六种天气、持久化、跨午夜与第一人称切换的验证见 WEATHER.md。本次为局部功能验证，未重复初版独立复核。

主楼按新增五张照片与用户纠正重建正面朝向及中轴线，保留界面、地图原始标定及其他建筑。桌面正面、中轴全景、夜景和手机窄视口已检查；实际绕过校训石并穿过柱廊中央，详见 MAIN-AXIS.md。

最新近照与中轴航拍用于继续细化主楼/柱廊，校准三者尺度、拉开主楼与柱廊距离，并加入双排叶饰柱头、石砌基座、实体窗框及近景入口。已检查桌面与手机，完成天气回归和实际通行，见 MAIN-DETAIL.md。

中轴对齐局部复核：按用户“笔直、对称”的反馈统一南门朝向、中央道路、湖岸及树列，取消旧斜线干扰并摆正总览镜头。桌面与手机截图确认主楼、南门中心投影共线，实际通行至校训石前，见 AXIS-ALIGNMENT.md；本次不扩展 UI 设计或重复独立全站复核。
