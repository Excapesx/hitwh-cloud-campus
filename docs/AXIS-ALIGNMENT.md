# 中轴线对齐与对景整理

用户明确反馈“整体不够笔直、对称”。本次延续整条中轴航拍参考，保留主楼、柱廊及校训石的先后位置和建筑细部，重点调整朝向、地面连续性与两侧对景。

## 调整

- 主楼和南门中心仍沿地图坐标连线。南门原来沿世界 Z 轴摆放，现连同敞开门扇、门前道路、步行边界、碰撞及夜间灯具统一旋转到中轴方向。漫游起点也落在轴心。
- 中轴大道控制点保持共线，在南门自带道路铺装处衔接；横向连接路在中轴附近按垂直方向整理。
- 移除原来穿过湖区、斜穿中央步道的两条小路，以及独立世界坐标矩形铺装。主楼前庭统一铺装覆盖旧道路切口，中央步道贯通至校训石广场。
- 中央步道宽 5.8，机动车大道宽 8，均为场景单位。两侧附属步道、绕湖步道和树列采用成对坐标，日月湖以相同轮廓镜像形成对景。保留湖岸的平滑曲线与石质驳岸。
- 校训石改为中央椭圆石材广场，半轴 10 与 8，使用窄嵌条围合，避免深色沥青再次切断中央步道。道路在广场南端收口，石体两侧留有步行空间。
- 中轴总览取消原来的 0.12 弧度侧偏，沿轴心取景；手机减少额外缩远量，使主楼至南门占据主要画幅。主楼和柱廊细节入口沿用原有操作。

这些调整服务于照片参照下的视觉对齐与对称布置。两湖实际岸线可能有差异，当前镜像轮廓不代表实测地形；未新增测绘精度声明，也没有发布用户照片或水印。
