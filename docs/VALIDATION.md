## 已验证

- `npm run build`：生成约 2.68 MB 的单文件 `index.html`。
- `npm run check`：69 个地点标识唯一；非出入口建筑中心位于校园边界内；15 段道路数据有效；巡览地点引用有效；图书馆、主楼、体育场的主要相对位置符合地图；初始漫游落脚点位于校园内；交付 HTML 不依赖外部脚本、样式或 CDN，原图已内嵌。
- 桌面 1440 × 960、手机宽度 390 × 844：场景、标注、小地图、工具栏可显示。独立复核意见为 ship，无阻塞问题；复核范围为这两种俯瞰截图及源码。
- 目录搜索“图书馆”返回对应地点，选择后镜头聚焦；搜索不存在的名称出现恢复入口；原图弹窗可打开并用 Escape 关闭。
- 第一人称成功获取 Pointer Lock；按住 W 后场景位置从 `[54.45, 1.7, 285.3]` 移至约 `[54.65, 1.7, 283.53]`，释放后可退出锁定。
- 六站巡览能启动并进入南门站；默认自转关闭。
- 浏览器设置为离线后，使用 `file:///.../index.html` 直接打开，69 地点的场景正常启动；内嵌原图解码宽度为 1600 像素。
- 上述运行过程中浏览器未记录页面 JavaScript 异常。
