## 建筑细节

柱廊使用独立 `colonnade.js`：双排柱、错缝石块基座与压顶、柱础环线、192 边径向采样的凹槽柱身、叶饰和涡卷柱头、横枋、筒灯、连续弧形层叠檐口、深色矩形饰板、花饰、顶部接缝和中央拱形饰冠。照片中的铭文不可读，未杜撰文字。实心部分单独登记碰撞，中央通道保持畅通。

主楼沿用南门的程序化石材微表面、粗糙度变化和局部阴影标准，增加真实厚度的窗框、外挑窗台、分格条、反射玻璃、檐口齿饰、阳台栏杆、门扇与把手、雨棚底板和灯具。大构件保留小倒角，远视下不可辨认的细窗条使用低面数几何；同材质合批。主楼玻璃分三种色阶与夜间亮度，不再整齐划一地全亮。夜间增加立面照明，轮廓灯只沿边线布置，屋顶面保持非发光。

详情增加“查看柱廊细节 / 返回主楼正面”，并支持 `#colonnade`。近景使用小近裁面，桌面 GTAO 聚焦柱廊；完整中轴视角恢复较大的近裁面，避免远处地面深度干涉。手机采用从中央步道略高处看柱廊的镜头，避开树列与校训石。
