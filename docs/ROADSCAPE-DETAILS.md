# 道路与树阵细化

本轮参考用户补充的两张道路实拍。第一张显示南门道路的法桐树廊、白色涂干、橙色警示带、沥青路面、黄色中心线、浅色边线和落叶。第二张显示生活区道路前的树池、长椅、白色涂干、橙色树干带、雨天反光路面与低层服务建筑。

模型中的主路现在按道路段生成连续的浅色路缘和人行带，车行道保留黄中心线与白边线。道路两侧树阵从原来的两个球形树冠改为五簇宽冠，树冠有不同高度和绿色层次，树干增加白色下段和橙色带，并加入可见分枝。树阵仍避开建筑、湖岸和可通行宽度，确保第一人称碰撞不被树干堵住。

两张照片能确认道路和树阵的材质与空间关系，无法确认每一段道路的树种或现场季节状态，因此模型使用法桐式宽冠作为统一示意。天气系统中的雨天会降低沥青粗糙度并产生湿润反射，树阵仍使用程序化材质。
