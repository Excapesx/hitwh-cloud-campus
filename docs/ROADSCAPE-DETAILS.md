# 道路与树阵细化

本轮参考用户补充的两张道路实拍。第一张显示南门道路的法桐树廊、白色涂干、橙色警示带、沥青路面、黄色中心线、浅色边线和落叶。第二张显示生活区道路前的树池、长椅、白色涂干、橙色树干带、雨天反光路面与低层服务建筑。

模型中的主路现在按道路段生成连续的浅色路缘和人行带，车行道保留黄中心线与白边线。道路、校园林地、中轴树列和南门侧景全部使用 EZ-Tree 的 Oak Large / Ash Large 生成树，保留真实树皮纹理、分级枝干和双面叶片卡片；不同位置按尺寸和朝向变化，树冠靠近建筑时按可用空间压缩，避免穿模。行道树树干下段增加白色涂干和橙色警示带，第一人称碰撞仍以树干位置避让建筑和道路。

两张照片能确认道路和树阵的材质与空间关系，无法确认每一段道路的具体树种，因此 EZ-Tree 采用 Oak Large 与 Ash Large 作为法桐/悬铃木式高分枝阔叶树的近似生成方案。天气系统中的雨天会降低沥青粗糙度并产生湿润反射，树阵继续使用本地内嵌纹理，不请求外部资源。
