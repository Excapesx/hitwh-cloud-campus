# 道路与树阵细化

本轮参考用户补充的两张道路实拍。第一张显示南门道路的法桐树廊、白色涂干、橙色警示带、沥青路面、黄色中心线、浅色边线和落叶。第二张显示生活区道路前的树池、长椅、白色涂干、橙色树干带、雨天反光路面与低层服务建筑。

同一条路两侧使用同一种树型，优先成对种植。南门中轴与体育场周边采用宽冠法桐式，学子路和教学区道路采用高冠行道树，生活区与湖岸采用圆冠树，环山路与山坡采用层叠松型。环山路沿校园边界的路段使用校内侧种植带。

四种模型沿用 EZ-Tree 的树皮纹理、分级枝干和双面叶片。近处保留完整细枝和 256 px 叶片纹理，远处用简化网格表现同一树冠。树木避开路面、人行带和纪念立牌前场。树冠靠近建筑时按空隙微调。天气系统中的雨天会降低沥青粗糙度并产生湿润反射。
