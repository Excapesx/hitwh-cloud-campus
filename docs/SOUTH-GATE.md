# 南门照片细化

后续材质和日间光影细化详见 [REALISM.md](REALISM.md)；以下保留建筑形体依据与通行验证。

## 本次依据

用户提供了三张南门实景照片：

- `228ac467856c26a63ffed72d65ad7f18.jpg`：夜间入口全景，用于确认三通道及主拱轮廓。
- `91bfc392745be00478e47211ba02854d.jpg`：日间正面全景，作为墙面颜色、整体比例、翼房、门前铺装与双臂路灯的主要参考。
- `b36d59156e5e1aaec2719e2853682aec.jpg`：立面近景，用于查看槽纹下柱、柱头、拱口叠线、校名牌匾与铁艺门。

照片中的标题、人物、品牌标志和水印不属于建筑，不作为场景贴图。原照片没有额外打包进 HTML 或公开仓库，模型使用程序化几何与运行时绘制的校名纹理。

## 模型变化

- 独立的中央大拱与左右小拱，拱洞真正留空。
- 两侧门卫翼房、窗台、拱形窗饰、水平墙面分带。
- 下层槽纹柱、柱础及叠层柱头，上层细柱与三联竖向装饰框。
- 四层屋顶檐线与“哈尔滨工业大学”校名牌匾。
- 向校园内敞开的双扇铁艺门及顶部曲线装饰。
- 门前车道、人行道、双黄线、斜纹分流线、交通锥、双臂路灯与低绿篱。

几何按材质合并，避免把每根铁艺栏杆和装饰线都变成独立绘制调用。拱洞通行与立柱、翼房碰撞分别登记。

## 查看与交互

打开根目录 `index.html` 后选择“查看南门细节”，或进入建筑目录搜索“南门”。文件 URL 加上 `#south-gate` 也可直接进入南门近景。

“到附近漫游”将视点放在门前，可使用 WASD 穿过中央入口。临街侧步行范围只扩展到门前铺装，仍受边界限制。南门近景隐藏其他建筑标注与地面选择光圈，避免挡住立面；“复位”返回全校。

## 验证

- `npm run build` 和 `npm run check` 通过；交付物约 2.69 MB，仍为离线单文件 HTML。
- 桌面 1440 × 960、手机宽度 390 × 844 已检查；待镜头到达稳定位置后截图。
- 第一人称成功锁定鼠标，由门前 `[54.45,1.7,324.76]` 向前移动，穿过南门至约 `[54.45,1.7,292.40]`。
- 校验脚本额外检查南门中央通路的步行范围及碰撞体，防止将整片拱墙登记为地面障碍。
- 浏览器没有记录页面 JavaScript 异常。

## 仍属估计的部分

照片缺少测量尺寸与完整背面、屋顶资料，因此总宽、总高、进深、柱距、背立面和门前设施位置均为照片估计。当前采用与原校园一致的日间材质及光照，没有模拟夜景灯光或复制校名字体的精确字形。这是一版依据照片细化的程序化模型，不属于摄影测量或扫描成果。
